# 原始需求

让文件管理器按**文件夹内的元数据**(`.folder.yaml`)增强显示,便于项目整理:

- **显示描述**:文件夹可显示一段自定义描述(中文或任意语言),磁盘上的真实名字和路径不变。**方案已定(2026-08-17)**:采用 caption 第二行显示(真名在上、描述在下),不做显示名替换;2026-09-25 起该字段统一称「描述」(`desc`)——理由见 `research.md`
- **文件注释**:给文件夹内的文件加一行注释,显示位置与描述相同
- **全局开关**:右键菜单切换描述显示,即时生效
- **实现策略**:纯 nautilus-python 插件,不改 nautilus 源码(2026-10-23 定);原「归档 / 分组视图」需求已放弃
